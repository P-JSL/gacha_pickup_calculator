# 확률·환급 계산식 및 모델 검증 

**적용 기준: v1.0.12 (2026-11-08).** 공개된 배너 규칙과 소프트 천장/아이템 풀에 관한 추정값은 구분하며, 실제 서버의 비공개 조건부 분포까지 완전히 재현했다고 주장하지 않습니다. [현재 릴리즈 노트](../RELEASE_NOTES_v1.0.12.md).

## 1. 확률 산식과 분리 원칙

### 한 번의 5★ 획득

희귀 등급의 n번째 뽑기 조건부 확률을 h(n), 확정 천장을 H라고 정의합니다.

- 최초 획득 시점: `P(T=n) = h(n) × ∏(i=1..n−1)(1−h(i))`
- n회 내 획득: `F(n) = 1 − ∏(i=1..n)(1−h(i))`
- 최초 1장 기대 뽑기: `E[T] = Σ(k=0..H−1) ∏(i=1..k)(1−h(i))`
- 장기 출현률: `r_model = 1/E[T]` (독립적으로 새로운 카운터가 시작되는 반복 모델에서만 성립)

`RateSchedule::expected_first_rare_pulls`과 `implied_rare_rate`로 위 식을 그대로 평가해 Analytics에 노출합니다. 이는 **현재 선택한 조건부 확률 함수의 수치**이며 게임의 실제 미공개 소프트 천장 곡선이라는 의미가 아닙니다.

`RateMode::PublishedOnly`: *공개 기본 확률 + 확정 천장만* 사용합니다. 이 모델에서 얻은 `1/E[T]`가 게임사가 표기한 **종합 출현률**과 다를 수 있습니다.

`RateMode::CommunityEstimate`: 게임별 공개 추정 소프트 천장/보드 조건부 확률을 사용합니다. 출처가 없는 숨은 서버 코드를 역설계했다고 주장하지 않습니다.

### 픽업 대상 및 전체 목표

- 일반 50:50/75:25 배너: 상태 `(목표까지 획득 수, 5★ 경과 횟수, 픽업 확정 플래그)`를 가지고 각 뽑기 확률 질량을 DP 전이합니다.
- 직접 픽업 카운터(스텔라 소라): 픽업 획득 실패 횟수와 일회성 120회 무료 수령을 별개로 추적합니다. 비픽업 5★는 픽업 카운터를 리셋하지 않습니다.
- 이환 Arc: 10개 단위로 결제하고 자연 발생 결과 10개의 다항 분포 및 6/8묶음 보장을 합성합니다. 보장 아이템의 **10연 내부 정확한 교체 순서**는 알려지지 않아 근사입니다.
- 환급 전 캐릭터/장비의 배너 결과는 별도로 DP 계산하되, 환급 재투입은 같은 시뮬레이션 경로에서 공유 상점 잔액을 유지합니다. 두 종류의 분위수를 따로 산출하여 더하지 않습니다.

## 3. 4★/A급 출현·픽업 보장과 환급

**문제:** 5★를 먼저 추첨한 후 '5★ 미등장' 분기에서 원래 공개된 4★ 기본 확률 `p4`를 그대로 재사용하면, 실제 4★ 확률이 `(1-p5) × p4`로 작아집니다.

**수정:** 4★ 기본률이 *전체 뽑기당 발생률*이라는 전제에서

`P(4★ | 5★가 아님) = min(1, p4 / (1−p5))`.

예시: 스텔라 소라 일반 캐릭터의 `p5=0.02, p4=0.04`라면 조건부 4★ 확률은 `0.0408163...`. 5★ 당첨과 배타적인 상황에서 전체 확률이 다시 4.00%가 됩니다. 기존 분기 그대로라면 실제 3.92%가 됩니다.

5★가 확정되는 시점에는 5★가 우선합니다. 고천장 위치에서 `p5+p4>1`인 경우에는 모든 등급의 기본률을 동시에 만족할 수 없으므로 조건부 값을 100%로 제한합니다. 4★ 천장 카운트는 5★ 등급 또는 4★ 획득 시 기존대로 초기화합니다.

- 스텔라 소라 캐릭터 4★ 기본률을 **8% → 4%**로 수정하며, 레코드는 **8%** 유지합니다.
- HSR(캐릭터 5.1%, 광추 6.6%), 명조(6%) 기본률은 기존 입력값을 유지합니다.
- 이환은 다른 게임의 4★ 교체 천장과 달리 **10회 누적 추가 A급 보상**이 있으므로 별도 처리합니다.

**v1.0.12 환급 보정:** 모든 게임에서 4성 캐릭터/A급은 최대 돌파 상태를 기본 가정으로 사용합니다. 스타레일 캐릭터 4성의 픽업 확률은 50%, 광추는 75%, 명조는 50%를 사용하며 실패한 경우 다음 4성은 픽업 확정으로 처리합니다. 비픽업 4성 결과의 캐릭터/장비 구성 50:50은 공식 확인되지 않은 모델 근사입니다. 이 보장 플래그는 5성 천장과 독립입니다. 광추·무기·레코드의 환급은 캐릭터의 풀돌 보상을 일괄 적용하지 않습니다.

## 4. 이환 보드 10회마다 추가 A급 1개 — 원본과 분리

GameWith의 게임 시스템 규칙에 따르면 10회마다 기존 보드 결과에 **추가** A급 아이템을 받습니다. 추가 아이템의 캐릭터/Arc 비중은 20%/80%입니다. https://gamewith.net/nte/74098

- 구 모델: 10회 동안 4★가 없으면 마지막 원래 결과를 4★로 대체하는 방식.
- 새 모델: 각 주사위 결과는 그대로 유지하고, 누적 10번째 사용 직후 추가 A급 획득 및 중복 가정에 따른 Warp Pieces만 적립합니다.
- 기본 추가 기대 환급 포인트(4성 캐릭터/A급 최대 돌파 기본 가정): `0.20 × A캐릭터환급(12) + 0.80 × A Arc환급(4) = 5.6 포인트/10회`. 중복 소유 상태에 따라 실제 기대값은 다릅니다.
- `character_four_star_pity`는 **이환에서는 10회 누적 보너스 진행도**로 해석하며 UI에 구분 표시합니다. 이는 보드에 표시된 진행도이므로 별도 서버 전이표를 추측하지 않습니다.

이환 A급 기본 아이템 확률(기존 입력값 6%)과 실제 72칸 위치별 A급 착지 분포는 여전히 불완전한 근사입니다. 공시 종합 A급 22.98%(캐릭터 11.67% + Arc 11.31%)를 별도 추가 보너스에 다시 기본률로 적용하면 **중복 계상 위험**이 있어 자동 대입하지 않습니다.

## 6. 환급 재투입의 실제 비용

시나리오별 사용권을 `N = D + X + P`로 기록합니다.

- `N`: 목표 완료까지 실제 소비한 모든 뽑기권
- `D`: 기존 전용권 및 캐릭터 획득 뒤 레코드 모집에만 사용된 전용 단위
- `X`: 이미 보유했거나 이전 뽑기에서 얻은 환급 포인트로 구매한 뽑기권
- `P`: 해당 경로를 성공시키는 데 처음부터 준비해야 할 추가 자유 뽑기권

최초 자유 필요량은 각 결제 직후의 최대 부족량:

`P = max_t [ C_t − floor(max(0, R_t − W_t) / price) ]_+`

(`C_t`: t시점까지 자유권으로 결제한 건수, `R_t`: 그 시점 보유 포인트, `W_t`: 돌파 상점에서 이미 소비한 누적 포인트).

실제 시뮬레이션에서는 현재 결제 후 받는 환급이 **그 결제에 쓰인 재화로 소급되지 않도록** 시점별 최대 부족량을 기록합니다. 명조 돌파용 산호는 티켓용 산호와 이중 계산하지 않습니다. 이환 보드 즉시 주사위 반환은 결제 후 다음 뽑기에만 사용할 수 있습니다. Arc 및 Stella 첫 10연의 패키지 가격은 패키지 내부 환급보다 먼저 결제합니다.

### 대시보드 환급 전후 공동 필요량

화면에 사용하는 **전체 목표 확률**과 **최종 추가 필요량**은 개별 캐릭터·무기 뽑기 수의 단순 합이 아니라 두 배너가 공유하는 최초 자유 재화로 환산한 확률변수 `B`의 분포를 이용합니다.

- `B_raw=max(0,N_char-D_char)+max(0,N_weapon-D_weapon)` (환급 전, 배너별 전용권 먼저 사용)
- `B_refund`: 동일한 단일 Monte Carlo 경로에서 모든 결제를 먼저 기록하고 이미 받은 환급권을 재투입한 뒤 시점별 최댓값으로 산출한 최초 자유권 수요
- `P_success=P(B_refund ≤ 보유 공유 재화)`
- `Q_p(B_refund)=p% 목표 성공을 위한 최초 총 필요 공유권`
- `추가 필요=max(0,Q_p(B_refund)-보유 공유 재화)`
- **표시용 분위수 절감 효과** `Q_p(B_raw)-Q_p(B_refund)`는 실제 한 시나리오의 환급 사용량 `X`와 서로 다른 통계량입니다.

전체 확률 그래프는 `B_raw`의 정확 CDF와 `B_refund`의 경험 CDF를 동일한 X축(최초 공유권)으로 그립니다. 이전 버전의 `combined`는 원시 총 뽑기 수량 분포여서 환급 후 공유권 성공률과 같은 X축에서 비교할 수 없었습니다. 최초 자유권 목표 분위수의 DKW 신뢰대역과 현재 보유량 성공확률의 Wilson 구간은 아래와 같이 각각 표본 오차를 나타냅니다.

## 7. 추정치의 신뢰구간

성공 확률 `P(P <= budget)`의 표본 불확실성은 기존 **Wilson 95% 구간**으로 평가합니다.

여기에 필요 재화의 분위수에 대해 **DKW–Massart 동시 95% 신뢰대역**을 도입했습니다. n개 독립 모의 경로의 표본 CDF를 `F_n`이라 하면

`Pr{sup_x |F_n(x) − F(x)| > ε} ≤ 2 exp(−2n ε²)`

따라서 95%에 대해 `ε = sqrt(ln(40)/(2n))`이며 진짜 q 분위수는 표본 `q−ε` ~ `q+ε` 순위 사이의 범위로 표시합니다.

- 20,000회: ε≈0.960%p
- 100,000회: ε≈0.429%p
- 1,000,000회: ε≈0.136%p

`q+ε ≥ 1`이면 유한한 표본만으로 상위 분위수의 보수적인 상한을 보증할 수 없으므로 **상한 미확정**으로 표시합니다. 확률 모델이 틀릴 가능성, 환급 보유 비율의 불확실성 및 비공개 서버 보드 전이는 이 구간의 포함 대상이 아닙니다.

## 8. 명시적인 남은 불확실성

1. 실제 서버의 5★ 소프트 천장/이환 보드 좌표별 마르코프 전이표는 제공되지 않았으므로 공식 완전 복원 불가.
2. 4★/A급의 캐릭터·무기 분리 확률, 이미 보유·풀돌인 캐릭터 분포, 개별 아이템의 중복 여부는 계정·배너에 따라 다름.
3. 이환 1/5개 주사위 반환 보드는 현재 각각 1.57%/0.38% 독립 추정이며 실제 착지 위치와 상관관계가 있을 수 있음.
4. 명조 첫 등장과 복제 산호, 돌파 1/2개 투자 우선 전략은 실제 상점의 구매 제한/개인 보유분 영향을 받음.
5. 스텔라 첫 10연의 900개 특전은 **동일한 한 번의 10연 구매**로 모델링합니다. 1~9회 개별 구매를 부분 3배 적립하는 모델이 아닙니다.
6. 실제 배너가 기념/콜라보/한정 특별 모집일 경우 일반 픽업과 다른 규칙을 적용할 수 있으므로 별도 배너 선택·상태 확인이 필요함.

검증에는 Windows/Linux 테스트·Clippy, 고정 시드의 순차/병렬 동등성, 4★ 기본률 회귀, 이벤트 4★ 픽업 환급, NTE 보드 추가 지급, 스텔라 10연 결제·디스크와 DKW 분위수 경계 테스트가 포함됩니다. 현재 배포 검증 결과: [v1.0.12 GitHub Actions](https://github.com/P-JSL/gacha_pickup_calculator/actions/runs/42464003186).
