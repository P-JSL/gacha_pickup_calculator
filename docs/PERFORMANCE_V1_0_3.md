# v1.0.3 실측 성능 측정 계약

## 기존 구조 변경의 효과와 한계

- v1.0.1의 책임별 `mod` 분리 자체는 런타임 비용을 낮추지 않습니다. 탐색성, 테스트 단위, 외부 접근 경계 및 변경 영향 범위가 개선됩니다.
- 정확한 PMF 합성은 소형·희소 입력에서 O(k1 × k2), 밀집 입력에서 선택된 FFT O(N log N)를 사용합니다. 큰 입력이라고 항상 FFT를 선택하는 것은 아닙니다.
- 단조 CDF 분위수는 O(log N)이고, 환급 없는 두 배너의 공동 잔여 필요분포는 한 번 합성해 여섯 개 신뢰도에서 재사용합니다.
- 게임별 배너 상태 전이 DP와 환급 Monte Carlo, 이미지 디코딩, GPU/GUI 렌더링은 위 복잡도에 포함되지 않습니다.

## 실행 방법

```sh
cargo test --locked --all-targets
cargo test --locked --release --test performance_regression -- --ignored --nocapture
```

릴리즈 CI의 `Measured performance reference` 단계는 동일 실행 환경에서 **2048×2048 밀집 PMF**의 직접 합성 및 FFT, 그리고 **20,000건** 분위수 조회의 선형/이진 알고리즘을 비교합니다. 출력 키는 `PERF_REFERENCE`입니다.

- 실행 환경(러너 CPU, 부하, 컴파일러)에 따라 숫자가 달라지므로 수치 실패 임계값은 설정하지 않았습니다. 올바른 결과를 수치 비교로 검증하며, 결과가 틀리면 테스트가 실패합니다.
- 실제 응답시간은 화면 이벤트·데이터 로딩·Monte Carlo 횟수 등 독립 요인의 영향을 받습니다. 프로파일링과 메모리 프로파일링은 별도로 필요합니다.
