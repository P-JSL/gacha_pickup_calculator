# 환급 분석 모델 · v0.2.4

> **모델 가정 기록:** 이 문서는 v0.2.4에서 정리한 계산 가정을 보존합니다. 게임사의 최신 실시간 배너 공지가 아니라는 점에 유의하고, 현재 프로그램 기능은 [README](../README.md)에서 확인하십시오.

이 문서는 공개 게임 규칙, 계정별 보유 상태, 커뮤니티에서 추정한 평균 효율을 분리하여 기록합니다. **평균 환급률을 확정 지급량으로 적용하지 않습니다.**

## 확률 모드

- 초기 선택: `RateMode::PublishedOnly` (공개된 기본 희귀도 확률 및 확정 천장).
- 사용자가 명시적으로 선택하면 `RateMode::CommunityEstimate`를 사용합니다. 스타레일·명조의 소프트 천장은 이 모드에서만 추정값이 적용됩니다.
- 이환 캐릭터의 공식 모드: 1~70회 기본 S급 0.99%/회, 71~89회 변환 보드 19.59%/회, 90회 확정. 해당 수치는 현행 모델에서 사용하는 공개 수치입니다.
- 이환 커뮤니티 모드: [보드 분석 게시글](https://arca.live/b/nevernesstoeverness/185272303)의 누적 첫 S급 확률을 **구간 조건부 성공률**로 환산한 근사입니다. 실제 72칸 보드의 위치별 상태 전이는 원문 요약만으로 완전히 재구성할 수 없으므로 구현하지 않습니다.

### 이환 커뮤니티 누적 확률 회귀 기준

| 주사위 횟수 | 첫 S급 누적 확률 |
|---:|---:|
| 10 | 9.13% |
| 20 | 17.88% |
| 30 | 25.59% |
| 40 | 32.81% |
| 50 | 39.17% |
| 60 | 45.00% |
| 70 | 50.27% |
| 71 | 59.86% |
| 80 | 94.24% |
| 89 | 99.18% |
| 90 | 100% (확정) |

해당 게시글은 메인 54칸, 캐릭터 9칸, 스킨 9칸 등 72칸 보드, 주사위 눈 1~6 균등(각 1/6), 보드 확률 추정과 시작 위치 의존성을 설명합니다. 실제 위치별 전이표가 충분히 명시되지 않아 본 프로그램에서는 **누적 확률에 일치하는 piecewise conditional hazard**를 구성합니다. 팬 분석의 71회 이후 착지 확률 19.4696%와 게시글의 70/71회 누적 확률표는 완전히 일치하지 않으므로 회귀 기준은 *명시된 누적값*을 사용하며, 확정 90회는 유지합니다. 캐릭터가 획득되면 확률 카운터는 처음부터 다시 적용됩니다. 이는 근사이며 유일하거나 공식적인 마르코프 전이모형이 아닙니다.

## 게임별 환급·별도 재화

| 게임 | 이용자 제공 비교 지표 (검증 전 추정) | 적용 기준 |
|---|---|---|
| 스타레일 | 스타라이트 티켓 환급 약 9~10% | 실제 4/5성 획득 및 중복·풀돌 가정에 따라 포인트 적립, 20개/티켓 재투입 |
| 명조 | 산호 환급 약 6.25~9.38% | 산호 8개/티켓, 돌파 우선 구매 전략 0/1/2개에 따라 결과 변동 |
| 스텔라 소라 상시/한정 캐릭터 | 약 14.6% / 24.6% | 현행 기본 캐릭터 배너는 한정 모집 모델; 모든 배너에 24.6% 일괄 적용하지 않음 |
| 스텔라 소라 최초 10회 | 약 45.3% | 3배 전문가 증명서 보너스는 해당 계정에서 남은 횟수를 **직접 입력**(기본 0회) |
| 스텔라 소라 레코드 | 약 15.3% | 실제 모집 중복 결과와 전문가 증명서로 모델링 |
| 이환 캐릭터 | 약 3.5~5% (초기), 8~12% (중복) | 직접 반환되는 주사위/중복 Warp Pieces를 다른 메커니즘으로 처리 |
| 이환 Arc | 약 6~8% | Arc 10회 묶음 및 상점 보상 가정 유지, 월별 제한 재고 미확인 |

**교차 재화 혼합 금지:** 스텔라 소라 한정 캐릭터 1회당 골든 디스크 30개(레코드 300개/1회의 10% 상당)는 *레코드 전용*으로 모으고 캐릭터 모집으로 직접 환산하지 않습니다. 캐릭터 모집 후 레코드를 진행할 때 같은 실험 경로에서 적립한 완전한 300개 묶음만 보유 레코드권에 추가합니다. 300개 미만 단위는 환산 없이 남습니다. 전문가 증명서는 별도의 상점 교환 재화입니다.

**주사위 재사용:** 이환의 1개 반환(1.57%)·5개 반환(0.38%)은 독립 근사이며 주사위를 소비한 **후에** 보상되어 다음 캐릭터 뽑기에만 사용할 수 있습니다. 보드 위치별 조건부 분포가 알려지면 별도 상태 전이모형으로 교체해야 합니다.

환급 확률과 계정별 보유 중복률은 시뮬레이션 파라미터이며, 공식 확률 모드를 선택해도 환급은 결정적 공식 지급률을 의미하지 않습니다. 계산 결과에 생성된 환급률을 캐릭터·장비별로 분리하고, 마지막 뽑기 이후 사용하지 못한 잔여 보상도 포함한다는 점을 UI에 표시합니다.

## 실험 한계 및 추후 확인

- 상시/픽업/이벤트 배너의 독립 상점 보너스, 월간 재고, 일부 Arc 보드 전용 재화가 완전하게 정의되지 않았습니다.
- 계정별 중복 소유 비율을 모르므로 특정 평균 환급률은 고정 보장치가 아닙니다.
- 스텔라 소라 초회 보너스가 디스크 보상에도 적용되는지는 확인되지 않아 3배 보너스는 전문가 증명서에만 적용합니다.
- 완전한 원본 보드 배치와 각 구역의 보장 타일을 나타내는 상태 전이표를 얻기 전까지 이환은 완전한 마르코프 보드 시뮬레이터라고 표현하지 않습니다.
