이 문서는 기존 보안 점검 항목과 v0.2.2까지 추가된 이미지 무결성 조치를 요약합니다. 전체 코드·의존성에 대한 독립 보안 감사를 새로 완료했다는 의미는 아닙니다. 최신 캐릭터·장비 데이터 검증 범위는 [카탈로그 검증 보고서](CATALOG_AUDIT_v0.2.2.md)를 참조하세요.

## 보안 검증 방법

```bash
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
cargo audit
python3 scripts/build_offline_images.py
```

`scripts/build_offline_images.py`는 외부 네트워크가 필요합니다. CI는 파일 변환 후 바이러스 검사, 릴리즈 자산 생성 및 SHA-256 검증을 수행합니다. **테스트 통과가 보안 취약점 부재를 증명하지는 않습니다**. 소프트웨어 구성요소, 바이너리 서명 여부, 공급망 자산 사용권 및 사용자 기기의 보안 수준은 별도로 관리해야 합니다.

## 향후 유지보수 주의

- 이미지 소스 변경 시 `approved_source_url` 및 Rust 허용 목록을 동시에 변경하고, 출처 소유권과 배포 가능 여부를 확인합니다.
- `src/signature_pairs.tsv`에 새 쌍을 등록할 때 해당 시점 공식 캐릭터·무기 배너를 확인하고 **ID 중심으로** 등록합니다. 이름 유사도나 목록 순서로 자동 매칭하지 않습니다.
- 사진이나 장비의 오류 신고 시 ID, 게임, 원본 자산 URL, 기대 이름 및 출처를 기록합니다. 단순 이미지 검색 유사도만으로 교체하지 않습니다.
- `cargo audit` 및 이미지 스캐너 결과는 출시 전 확인하되, 새로운 외부 공급망 보안 권고가 나올 수 있으므로 정기 점검이 필요합니다.
