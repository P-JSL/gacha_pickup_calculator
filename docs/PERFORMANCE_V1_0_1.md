# v1.0.1 성능 분석과 검증 기준

> **과거 설계/측정 기준:** v1.0.1에서 도입한 최적화의 근거입니다. 실제 v1.0.3 Linux CI 측정 결과는 [최신 성능 보고](PERFORMANCE_V1_0_3.md)를 참조하십시오.

| 경로 | 기존 비용 | 변경 후 비용 | 조건 |
|---|---|---|---|
| 두 PMF 직접 합성 | O(n×m) | O(k1×k2) 또는 FFT O(N log N) | k는 비영 항 수, FFT는 밀집·큰 분포만 |
| `Distribution::quantile` | O(n) | O(log n) | CDF가 단조 비감소 |
| 비환급 예산 6개 성공률 | 6회 O(n log B) 검색 | 공동 필요분포 1회 합성 + 6×O(log N) | 환급 미사용 경로 |
| 배너 DP | 상태 공간 의존 | 상태 공간 의존 | 기본 상태 전이 유지 |
| 환급 Monte Carlo | O(표본×시도) | 동일 | 계정별 환급 추정 유지 |

- N은 합성 배열 길이의 다음 2의 거듭제곱이고 B는 공동 예산 상한입니다. 비영 항이 극히 적은 분포는 직접 계산이 더 효율적입니다.
- 확률 분포는 정밀한 부동소수점 계산에 의존합니다. FFT 결과는 음수/비정상 값·총 확률질량 차이를 확인하고, 문제가 발생하면 직접 경로로 복귀합니다.
- 공동 예산의 잔여 확률변수는 `max(0, 캐릭터 뽑기 - 캐릭터 전용권) + max(0, 장비 뽑기 - 장비 전용권)`입니다. 이 분포의 CDF는 기존 환급 없는 적응 배분 성공 확률과 같아야 합니다.
- 원본과 새 분포 결과 비교, 충분한 예산에서 100% 성공, 4개 게임의 확정 천장 및 환급 시뮬레이션 독립성을 회귀 테스트합니다.
- O(N log N) 개선은 해당 분포 합성 경로에 한정됩니다. GUI, I/O, 복잡한 배너 상태 전이 및 Monte Carlo까지 포함한 엔드투엔드 O(n) 보장은 불가능합니다. 실측 전 속도 개선 배수를 주장하지 않습니다.
