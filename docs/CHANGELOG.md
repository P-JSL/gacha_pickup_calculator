# 변경 이력 · Gacha Pickup Calculator

현재 릴리즈는 **v0.2.5**입니다. 구버전 개별 문서와 스크린샷 대신 과거 배포 상세는 [GitHub Releases](https://github.com/P-JSL/gacha_pickup_calculator/releases)에서 확인할 수 있습니다.

## v0.2.5 (2026-11-06)
- Dashboard의 마지막 KPI를 목표 성공률 기준 **추가 필요 재화**로 개선. Dashboard/Analytics 양쪽에 기보유 캐릭터·장비 및 전용권/공용권 반영 부족분 패널 표시.
- 목표 장수에서 기보유 캐릭터/장비를 차감해 남은 목표 수량을 동적으로 계산. 기보유 목표 이상이면 해당 배너 비용은 0.
- 환급 적용 시 기존 Monte Carlo 환급 재투입 필요 예산의 분위수 사용. 환급 미적용 시 캐릭터·장비 전용권을 고정하고 공용권을 적응 배분하는 정확한 DP의 최소 필요량 탐색.
- 현재 공용권 및 프리미엄 재화를 1회 교환 최소 단위까지 차감하여 추가 공용 뽑기/게임 재화 부족분 표시. 각 배너 독립 분위수의 단순 합산 방지.
- 단위 테스트: 4개 게임 기보유 장수 변화, 전용권 분리, 공용권 중복 계산 방지, 잔여 재화 159/160, 확률 기준, 환급 재투입.
- 입력 변경 후 재계산 전에는 오래된 부족분을 표시하지 않음.

## v0.2.4 (2026-11-06)
- 확률 모드 초기 선택을 PublishedOnly(공개 기본 확률 + 확정 천장)로 설정. 커뮤니티 확률은 수동 선택 가능.
- 이환 72칸 보드 커뮤니티 분석의 첫 S급 누적 확률 기준표를 공식 모드와 분리한 조건부 확률 근사로 반영.
- 이환 보드에서 반환되는 주사위 1개/5개(커뮤니티 가정)는 이후 캐릭터 뽑기에만 재사용.
- 스텔라 소라 캐릭터 뽑기에서 생성되는 레코드 전용 Gold Disc 별도 적립과 계정별 초회 남은 횟수(기본 0회)를 반영.
- 캐릭터와 장비의 시뮬레이션 환급 생성률을 따로 표시하고 별도 레코드 전용 재화 합산 오류를 차단.
- [환급 가정과 한계](REFUND_CALIBRATION.md).

## v0.2.3 (2026-11-06)
- 프로그램 시작 시 GitHub 커밋 고정 카탈로그·매핑·이미지 매니페스트 갱신. 업데이트 불일치 시 기존 데이터 유지.
- 캐릭터 이미지의 버전별 generation 검증을 추가해 이전 로딩 결과가 새 PNG를 덮어쓰지 않도록 처리.
- RwLock poison fail-closed 처리, SHA-256·파일 크기·디코더 검증 유지.
- 확률 DP의 버퍼 재사용/사전 계산으로 반복 할당을 감소시킴. 수학적 계산 규칙은 불변.
- 최신 프로그램 릴리즈 확인 및 Settings 표시. 바이너리 무인 설치와 공식 발표 자동 수집은 미지원.
