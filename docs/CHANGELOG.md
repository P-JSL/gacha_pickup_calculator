# 변경 이력

**현재 정식 버전: v1.0.12 (2026-11-08)**

## v1.0.12

- 네 게임 모두 4성 캐릭터/A급 최대 돌파 보유를 **기본 100% 가정**으로 설정했습니다. 고급 설정에서 비율 변경이 가능합니다.
- 스타레일과 명조의 4성 픽업 보장, 캐릭터/광추·무기 결과별 중복 환급을 구분했습니다. 비픽업 4성의 캐릭터·장비 비중은 50:50 근사입니다.
- 스텔라 소라의 최대 돌파 4성 여행가 70개, 레코드 80개 전문가 증명서를 적용했습니다.
- 기존 환급 재투입, 병렬 Monte Carlo, 그래프 상단 배치와 수동 시뮬레이션 실행 정책을 유지합니다.
